Consigne

Depuis js/animations.js, écrivez le code JavaScript pour créer des animations GSAP selon les indications de chaque exercice.

N'oubliez pas d'installer la librairie GSAP dans un premier temps (via npm install gsap) et de l'importer ensuite tout en haut du fichier js/animations.js

Exemple

// gsap.to("#js-exercise-1", { x: 100, duration: 2 }); // L'élément se déplace de 100px vers la droite en 2 secondes
