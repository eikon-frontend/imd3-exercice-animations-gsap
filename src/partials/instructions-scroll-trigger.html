Consigne

Depuis js/scroll-trigger.js, écrivez le code JavaScript pour créer des animations au scroll avec le plugin ScrollTrigger de GSAP selon les indications de chaque exercice.

Conseil: Utiliser les 'markers' pour visualiser les points de contact.

Exemple

// Animation déclenchée par le scroll avec des marqueurs pour débugger
gsap.to(".box-1", {
  x: 100,
  duration: 2,
  scrollTrigger: {
    trigger: ".box-1",
    start: "top center",     // Démarre quand le top de l'élément atteint le centre du viewport
    markers: true            // Affiche les marqueurs pour visualiser les points de contact
  }
});
